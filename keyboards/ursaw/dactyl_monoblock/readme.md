# Dactyl Monoblock

Handwired Dactyl-style monoblock keyboard (5x12 matrix, 58 keys) with a Pro Micro (ATmega32U4).

* Keyboard Maintainer: ursaw
* Hardware Supported: Pro Micro
* Hardware Availability: Handwired

Make example for this keyboard (after setting up your build environment):

    make ursaw/dactyl_monoblock:default

or with Docker:

    util/docker_build.sh ursaw/dactyl_monoblock:default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information.
